# 頭字語および略語

| 略語 | 意味 |
| --- | --- |
| ARQ | Automatic Repeat reQuest。欠落したpacketの再送を要求する制御。 |
| OTel | OpenTelemetry。telemetry dataの生成、収集および転送に用いる標準。 |
| OTLP | OpenTelemetry Protocol。OpenTelemetryのtelemetry dataを転送するprotocol。 |
| RIST | Reliable Internet Stream Transport。 |
| RTP | Real-time Transport Protocol。 |
