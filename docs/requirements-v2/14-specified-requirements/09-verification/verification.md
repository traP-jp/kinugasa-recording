# 検証

## camera間の時間軸ドリフト

- 同期可能な同一の映像を、H.264形式、30 fpsで複数のcamera入力として10分間送信する。
- 各入力へ独立して最大100 msのネットワークジッタを付加する。packet lossは付加しない。
- 録画開始付近と録画終了付近について、optical flowベースの同期システムを用いてcamera間の時間オフセットをframe単位で算出する。
- 各cameraの組について、録画開始付近と録画終了付近の時間オフセットの差の絶対値を求める。
- すべてのcameraの組について、時間軸ドリフトが2 frame以下であることを確認する。
